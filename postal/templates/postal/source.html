What the file must contain
  • CSV: a header row with these columns, in any order: Circle Name, Region Name, Division Name, Office Name, Pincode, OfficeType, Delivery, District, StateName. Spaces, underscores and letter case in column names are ignored.
  • JSON, detected automatically: bharat-post-dir's own download from /api/v1/export/ (its source and date fill in the fields below if you leave them empty), a data.gov.in API response ({"records": [...]}), or a plain list of offices. Each office uses the CSV column names above or bharat-post-dir's field names (office_name, pincode, office_type, delivery, district, state, circle, region, division). Problems are reported by record number.
  • Optional Latitude and Longitude columns or fields. Other columns are ignored.
  • Six-digit PINs that do not start with 0. Every field except Region Name must be filled in.
  • Exact repeated rows are merged. An office listed more than once with different details (same PIN, state, district and office name) is kept in every version and counted.
  • UTF-8 text (in Excel, “CSV UTF-8”), at most {{ max_mb }} MB.
